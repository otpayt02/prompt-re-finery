# One-Night AI Stack Workflow

## Goal

Turn a fuzzy app idea into a scoped portfolio-ready MVP using AI assistance without letting scope explode.

## Workflow

1. Define the painful problem.
2. Identify the target user.
3. Lock one core workflow.
4. Define the input, transformation, and saved output.
5. Cut everything outside the MVP.
6. Scaffold the app.
7. Build a fake local vertical slice.
8. Add real API or persistence only after the fake flow works.
9. Add loading, error, and empty states.
10. Deploy and write the README.

## Default tools

- ChatGPT for planning.
- Codex in VS Code for implementation.
- PowerShell 5 for command-line steps.
- GitHub for commits and PRs.
- Supabase for auth/database if needed.
- Vercel for portfolio/demo deployment.

## Stop-building line

Stop when a user can complete the single core workflow from input to saved output without manual explanation.
