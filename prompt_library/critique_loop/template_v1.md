# Critique Loop Prompt Template — v1

## Purpose

Review an existing artifact, identify weaknesses, and produce a better version or improvement plan.

## Required context fields

- `artifact`: The thing to critique.
- `success_criteria`: What good looks like.
- `audience`: Who the artifact is for.
- `constraints`: Limits on changes.

## Preferred output structure

1. What works.
2. What does not work.
3. Highest-impact fixes.
4. Revised version or action plan.
5. Critique checklist for next pass.

## Critique dimensions

- Is feedback specific?
- Are fixes prioritized?
- Does the revised version improve the original goal?
